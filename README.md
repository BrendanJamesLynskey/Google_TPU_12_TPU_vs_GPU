# TPU vs GPU &mdash; Two Architectural Philosophies

Side-by-side comparison of TPUs and modern GPUs across compute granularity, scheduling (static-compiler vs dynamic-warp), memory model (scratchpad vs cache), compilation (AOT graph vs JIT kernel), pod fabric (3D-torus + OCS vs NVLink + InfiniBand), numerics (bf16 / FP8 / FP4 trajectory), where each one wins, and the cloud-only TPU constraint. Closes the 12-deck series.
